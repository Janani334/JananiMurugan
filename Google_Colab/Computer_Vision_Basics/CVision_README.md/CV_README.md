COMPUTER VISION BASICS

* Introduction

This repository contains my beginner-level practice in Computer Vision using Python and OpenCV. These exercises were completed during a Computer Vision training session using Google Colab.

During the session, I learned the basic concepts of image processing and practiced working with images using Python and OpenCV.

* Topics Covered

1. Displaying Images
   Practiced reading and displaying images using Python and OpenCV.

2. BGR to RGB Conversion
   Practiced converting images from BGR format to RGB format for proper image representation.

3. Color Image to Grayscale
   Practiced converting color images into grayscale images to understand image intensity levels.

4. Selecting Specific Parts of an Image
   Practiced selecting and working with specific regions of an image using image coordinates.

5. Image Blurring
   Practiced applying blur to images as a basic image processing technique.

* Tools Used

- Python
- OpenCV
- Google Colab

* Learning Outcome

This practice helped me understand the basics of Computer Vision and image processing. I gained hands-on experience in reading, displaying, converting, selecting, and modifying images using Python and OpenCV.

This repository represents my learning and practical work from the Computer Vision training session. I look forward to exploring more Computer Vision concepts and practical applications.
