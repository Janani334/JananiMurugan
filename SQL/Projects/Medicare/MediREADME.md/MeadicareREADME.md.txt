🏥 HOSPITAL ANALYTICS DATABASE – SQL PROJECT
=============================================

📌 PROJECT OVERVIEW
-------------------------------

Hospital Analytics Database is a relational database project developed
using SQL and MySQL Workbench.

The project focuses on managing and analysing healthcare-related data,
including hospitals, departments, doctors, patients, appointments,
consultations, feedback, and other related records.

The database contains interconnected tables with appropriate Primary Key
and Foreign Key relationships to support structured data management and
analysis.


🎯 PROJECT OBJECTIVES
---------------------------------

1. Design a structured relational healthcare database.
2. Create and manage multiple interconnected tables.
3. Establish relationships using Primary Keys and Foreign Keys.
4. Insert and manage healthcare-related records.
5. Develop SQL queries to retrieve meaningful information.
6. Analyse data using filtering, sorting, grouping, aggregate functions,
   and JOIN operations.

🔗 DATABASE RELATIONSHIPS
---------------------------------------

The database uses relational connections between tables through Primary
Keys and Foreign Keys.

These relationships allow information from multiple tables to be
combined and analysed using SQL JOIN operations.


📈 SQL ANALYSIS
------------------------

The project includes SQL queries for analysing healthcare data, including:

• Finding doctors based on gender and experience.
• Retrieving hospitals based on location.
• Displaying patient and member information.
• Counting appointments and other records.
• Using aggregate functions for data analysis.
• Combining information from multiple tables using JOINs.
• Grouping records using GROUP BY.
• Filtering grouped results using HAVING.
• Retrieving specific records using WHERE.
• Sorting results using ORDER BY.
