🏥 HEALTHPLUSCARE HEALTHCARE DATABASE – SQL PROJECT


📌 PROJECT OVERVIEW

HealthPlusCare Healthcare Database is a relational healthcare database project developed using
SQL and MySQL Workbench. It focuses on managing and analysing healthcare data across clinics, specialists, members, 
consultations, laboratory services, billing, payments, claims, and related operations.


🎯 PROJECT OBJECTIVES

The project focuses on designing a structured healthcare database, establishing relationships between entities, 
performing data profiling and cleaning, and developing SQL queries to generate meaningful healthcare and operational insights.


🧹 DATA PROFILING & CLEANING

The project includes data profiling to identify missing values, inconsistent formats, invalid entries, and other data-quality issues.

SQL UPDATE statements were used to standardize inconsistent values and improve data consistency before analysis.


📊 DATA ANALYSIS

The project includes analysis of:

• Member and specialist information
• Clinic and consultation activity
• Telemedicine services
• Specialist consultation fees and experience
• Laboratory tests and results
• Billing, payments, and claims
• Feedback and specialist performance
• Healthcare packages and subscriptions


🔑 SQL CONCEPTS USED

CREATE DATABASE • CREATE TABLE • INSERT INTO • UPDATE
SELECT • WHERE • ORDER BY • GROUP BY • HAVING
INNER JOIN • LEFT JOIN • Aggregate Functions
Subqueries • Window Functions
Primary Keys • Foreign Keys • Constraints


📈 ADVANCED SQL

Window Functions such as ROW_NUMBER(), RANK(), LAG(), and LEAD() were used for ranking, comparison, and analytical insights.
