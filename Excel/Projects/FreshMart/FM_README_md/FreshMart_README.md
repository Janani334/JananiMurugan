FRESHMART SALES TRANSACTIONS ANALYSIS

1. Project Overview

This project analyzes FreshMart sales transaction data using Microsoft Excel. The analysis focuses on understanding sales, revenue, profit, product performance, regional performance, customer membership, and sales channels.

2. Project Objectives

The main objective is to clean and analyze FreshMart's sales data and convert the transaction records into meaningful business insights. The analysis helps identify sales trends, profitable categories, and important business performance patterns.

Key objectives include:

• Analyze monthly revenue and profit.

• Compare product category performance.

• Analyze sales performance by region.

• Understand revenue based on customer membership levels.

• Compare revenue across different sales channels.

3. Dataset Categories

The project contains multiple datasets related to FreshMart's business operations:

• Sales Transactions

• Customers

• Employees

• Products

• Stores

• Suppliers

The Sales Transactions dataset contains details such as invoice number, transaction date, customer, product, store, quantity, unit price, discount, sales amount, and profit.

4. Analysis Performed

The project includes the following analyses:

• Monthly Revenue and Profit Trend

• Product Category Performance

• Regional Sales Performance

• Membership Revenue by Region

• Revenue by Sales Channel and Day Type

5. Key Insights

The analysis provides the following major insights:

• Total sales revenue is approximately 2.87 million.

• Total profit is approximately 737 thousand.

• October recorded the highest sales revenue.

• Beverages generated the highest sales revenue among product categories.

• Bakery generated the highest profit.

• The South region contributed the highest sales revenue.

• Gold membership customers generated the highest revenue.

• In-Store sales generated the highest revenue among sales channels.

6. Tools and Techniques

• Microsoft Excel

• Data Cleaning

• Pivot Tables

• Data Analysis

• Business Reporting

• Revenue and Profit Analysis

7. Project Outcome

This project demonstrates the use of Excel to clean, organize, analyze, and summarize real-world sales data. The results provide useful insights into FreshMart's sales performance and can support better business decision-making.

8. Conclusion

The FreshMart Sales Transactions Analysis provides a clear overview of sales and profitability using Excel-based analysis. It demonstrates fundamental skills in data cleaning, Pivot Tables, business analysis, and reporting.
