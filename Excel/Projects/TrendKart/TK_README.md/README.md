\# TrendKart Fashion Enterprise – Sales \& Business Analytics



\## 1. Business Understanding



TrendKart Fashion Enterprise is a retail business dealing with multiple product categories, brands, stores, regions and sales channels. The business generates transaction-level sales data that can be analyzed to understand sales performance, profitability and customer purchasing patterns.



This project focuses on transforming raw retail data into meaningful business information to help management monitor performance, identify opportunities and make data-driven decisions.



\## 2. Project Objective



The objective of this project is to analyze TrendKart Fashion Enterprise's sales data to evaluate \*\*sales performance, profitability, customer behavior, product performance and regional trends\*\*.



The project aims to develop meaningful \*\*KPIs and an interactive Excel dashboard\*\* that provide actionable insights and recommendations for improving business performance.



\## 3. Business Questions



\* Which product categories generate the highest sales?

\* Which regions and store types perform better?

\* How do sales and profit change over time?

\* Which sales channels and payment modes contribute more?

\* Which brands are the top performers?

\* How do membership segments contribute to sales?

\* Which customers contribute the highest sales?

\* What is the regional return performance?

\* How are store targets distributed?



\## 4. Dataset Overview



The project uses the \*\*TrendKart Fashion Enterprise sales dataset\*\* in Microsoft Excel.



| Dataset / Sheet        | Purpose                         |

| ---------------------- | ------------------------------- |

| Raw\_Sales\_Transactions | Original transaction data       |

| Sales\_Cleaned          | Cleaned data used for analysis  |

| Customers\_Cleaned      | Customer information            |

| Products\_Cleaned       | Product and brand information   |

| Stores\_Cleaned         | Store and regional information  |

| Data\_Quality\_Log       | Data-quality issues and actions |

| Pivot\_Tables           | Analytical summaries            |

| Dashboard              | Final interactive dashboard     |



The cleaned `Sales\_Cleaned` dataset contains \*\*3,000 transactions and 36 analytical columns\*\* covering sales, customers, products, stores, payments, returns and profitability.



\## 5. Data Profiling \& Cleaning



Data profiling was performed to identify \*\*duplicates, missing values, inconsistent formats, spelling errors and invalid values\*\* before analysis.



The identified issues were documented in the Data Quality Log and corrected or validated before the final analysis.



\### Major Data Cleaning Activities



| Data Issue                   | Action Taken               |

| ---------------------------- | -------------------------- |

| Duplicate invoices           | Identified and reviewed    |

| Missing IDs                  | Identified and handled     |

| Date inconsistencies         | Standardized               |

| Quantity format issues       | Converted to numeric       |

| Payment mode inconsistencies | Standardized               |

| Return status errors         | Corrected                  |

| Customer data issues         | Validated and standardized |

| Product category errors      | Corrected                  |

| Store status errors          | Standardized               |

| Employee status errors       | Corrected                  |



\## 6. Data Analysis



The cleaned data was analyzed using \*\*Excel PivotTables, PivotCharts, calculated fields and aggregations\*\*.



The analysis covers sales, profit, products, brands, regions, stores, customers, memberships, payment modes, sales channels and returns.



\## 7. Tools \& Techniques



| Area                | Tools / Techniques             |

| ------------------- | ------------------------------ |

| Tool                | Microsoft Excel                |

| Data Profiling      | Data-quality checks            |

| Data Cleaning       | Standardization and validation |

| Data Transformation | Calculated and lookup fields   |

| Data Analysis       | PivotTables and aggregations   |

| Visualization       | PivotCharts and charts         |

| KPI Development     | Excel calculations             |

| Dashboard           | Interactive Excel Dashboard    |



\## 8. KPIs



The dashboard contains \*\*four primary KPI cards\*\* to provide a quick overview of overall business performance.



| KPI                |         Value |

| ------------------ | ------------: |

| Total Sales        | ₹92,27,179.96 |

| Total Profit       | ₹18,01,437.12 |

| Total Transactions |         3,000 |

| Profit Margin      |        19.52% |



\## 9. Dashboard



The \*\*TrendKart Fashion Enterprise Dashboard\*\* provides a consolidated view of overall business performance.



It combines the four key KPIs with product, regional, customer, brand, payment, return and store-level analysis to help management understand business performance from different perspectives.



\### Dashboard Preview



!\[TrendKart Fashion Enterprise Dashboard](Dashboard/TrendKart\_Dashboard.png)



\### Dashboard Components



| No. | Analysis                          | Purpose                                  |

| --: | --------------------------------- | ---------------------------------------- |

|   1 | Sales by Product Category         | Identify high-performing categories      |

|   2 | Regional \& Store-Type Performance | Compare regional performance             |

|   3 | Monthly Revenue \& Profit Trend    | Track performance over time              |

|   4 | Sales Channel \& Payment Mode      | Analyze channel and payment contribution |

|   5 | Top 10 Performing Brands          | Identify leading brands                  |

|   6 | Regional Return Analysis          | Monitor return performance               |

|   7 | Membership Spend \& Discounts      | Analyze customer segments                |

|   8 | Top Customers                     | Identify high-value customers            |

|   9 | Store Target Distribution         | Analyze store target allocation          |



\## 10. Key Insights



The dashboard analysis produced the following key business findings.



| Area          | Key Insight                                                                                    |

| ------------- | ---------------------------------------------------------------------------------------------- |

| Products      | \*\*Women Sarees\*\* recorded the highest category sales at approximately \*\*₹11.03 lakh\*\*.         |

| Regions       | \*\*South Zone 1\*\* recorded the highest sales at approximately \*\*₹44.63 lakh\*\*.                  |

| Sales Channel | \*\*Offline sales\*\* contributed approximately \*\*₹60.49 lakh\*\*, higher than Online sales.         |

| Payment Mode  | \*\*UPI\*\* recorded the highest sales contribution at approximately \*\*₹26.19 lakh\*\*.              |

| Brands        | \*\*Grt Jewellers\*\* was the top-performing brand with approximately \*\*₹5.51 lakh\*\* in sales.     |

| Membership    | \*\*Regular members\*\* generated the highest sales contribution at approximately \*\*₹29.74 lakh\*\*. |

| Returns       | Returned transactions represented approximately \*\*4.87%\*\* of total transactions.               |

| Monthly Trend | \*\*October 2024\*\* recorded the highest monthly sales at approximately \*\*₹15.19 lakh\*\*.          |



\## 11. Recommendations



Based on the dashboard insights, the following recommendations are proposed.



| Business Area  | Recommendation                                                                         |

| -------------- | -------------------------------------------------------------------------------------- |

| Products       | Increase inventory for consistently high-performing categories and brands.             |

| Regions        | Replicate successful practices from high-performing regions in lower-performing areas. |

| Customers      | Strengthen loyalty programs and targeted membership offers.                            |

| Digital Sales  | Improve online promotions and customer engagement.                                     |

| Payments       | Continue promoting UPI and other convenient digital payment options.                   |

| Returns        | Analyze return causes and take corrective actions to reduce returns.                   |

| Seasonal Sales | Plan promotions around peak periods and investigate low-performing months.             |

| Inventory      | Use sales trends to improve inventory planning and product availability.               |



\## 12. Project Outcome



The project transformed raw retail transaction data into a structured analytical solution covering \*\*sales, profitability, products, brands, customers, regions, stores, channels, payments and returns\*\*.



The final interactive dashboard provides a clear view of business performance and supports \*\*data-driven decision-making, sales planning, customer engagement, inventory management and profitability improvement\*\*.



\## Project Workflow



\*\*Business Understanding → Project Objective → Business Questions → Data Profiling → Data Cleaning → Data Analysis → KPI Development → Dashboard Development → Insights → Recommendations\*\*
